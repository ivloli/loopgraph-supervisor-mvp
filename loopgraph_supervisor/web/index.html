VERIFICATION

验证证据

由 Supervisor 执行命令并保存 exit code、stdout 和 stderr，不接受 Agent 自报成功。

VERSION CONTROL

版本与回滚

每个版本绑定 workflow 和 Git commit；dirty worktree 会拒绝回滚。

AUDIT TRAIL

活动日志

追加式状态转换记录，用于观察、故障定位和恢复解释。

NEW WORKFLOW

创建受控任务

源仓库必须 clean；A 版会创建独立 worktree，避免多个 Agent 互相污染。

启动后会发生什么？创建 durable workflow → 创建 Git worktree → DSH 执行 → 独立命令验证 → HITL 或版本晋级。
